# Portfolio Paul Faudois

Ce site correspond à la version 6 de ton portfolio, **avec les mentions « E5 » retirées de l’interface**. Les contenus du stage RCM, du CV et de la veille DLSS sont conservés.

## Pour l’ouvrir sur ton ordinateur

Ouvre `index.html` dans le dossier `Portfolio Paul Faudois`. Son onglet s’appellera maintenant **Accueil | Portfolio Paul Faudois**. Les autres onglets porteront aussi le nom du portfolio.

L’adresse du navigateur commencera toujours par `file:///` ou le chemin de tes dossiers lorsque tu consultes un fichier localement ; modifier le HTML ne permet pas d’en faire une adresse Internet courte.

## Obtenir un lien comme GitHub Pages

- Place **tous les fichiers et sous-dossiers contenus dans ce dossier**, pas le ZIP et pas forcément le dossier lui-même, à la racine du dépôt GitHub qui publie ton site.
- Dans les réglages GitHub du dépôt, sous **Settings → Pages**, active le déploiement depuis la branche appropriée si ce n’est pas déjà fait.
- Avec un dépôt nommé `Portfolio`, l’adresse publique est normalement `https://TON-PSEUDO.github.io/Portfolio/` une fois le déploiement effectué.
- L’URL d’exemple `https://ymaaaaa.github.io/Portfolio/` appartient au compte `ymaaaaa` : elle ne devient pas automatiquement l’adresse de ce portfolio.
- Le **titre du site** et l’**adresse web** sont deux réglages distincts : nommer le site « Portfolio Paul Faudois » n’impose pas de changer le nom du dépôt.

## Modifier les contenus

- `index.html` : accueil et parcours scolaire
- `cv.html` : CV et lien PDF
- `stages.html`, `stage-rcm-ansible.html`, `stage-rcm-support.html` : stage RCM

- `favicon.svg` : icône du site dans l’onglet

Avant de publier, vérifie que les documents personnels et les éléments issus du stage sont autorisés à la diffusion.
